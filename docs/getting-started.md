# Getting started

1. Install the extension using the [README](../README.md#install).
2. In Visual Studio, open **View → Other Windows → DeepSeek AI Assistant**.
3. Open the account or settings interface and provide an API key obtained from the [DeepSeek Platform](https://platform.deepseek.com/).
4. Select an available model.
5. Enter a prompt and submit it to start a conversation.

The extension requires a valid DeepSeek API account and network access for live requests. Model availability is controlled by the upstream service and the account's access.

## Working with selected code

Select code in the editor and use the extension's **Explain with DeepSeek** or **Refactor with DeepSeek** command. Review generated suggestions before applying them to a project.
